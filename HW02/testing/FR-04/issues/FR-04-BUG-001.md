# [FR-04][Bug] Backend không validate `name` — chấp nhận name rỗng, space, null, và vượt quá 255 ký tự

**Labels:** `bug`, `FR-04`, `black-box-testing`, `severity: critical`

---

## 1. Tóm tắt (Summary)

Endpoint `PUT /api/users/me` không thực hiện validation cho trường `name`. Backend chấp nhận tất cả các giá trị không hợp lệ (name rỗng, name chỉ có khoảng trắng, name null, và name vượt quá 255 ký tự) và vẫn trả về `200 OK`. Điều này vi phạm yêu cầu cơ bản về dữ liệu người dùng.

---

## 2. Nguồn spec / kỳ vọng (Expected Behavior)

- **Tài liệu tham chiếu:** `contexts/README.md` — FR-04 §2, dòng 64
- **Trích nội dung spec:**
  > "Người dùng đã đăng nhập có thể cập nhật: **Họ Tên**..."
- **Mức độ rõ ràng của spec:** `[Cần xác nhận]` — spec không nêu rõ ràng `name` có bắt buộc không và max length là bao nhiêu. Tuy nhiên, theo thông lệ chung, họ tên không được rỗng và có giới hạn độ dài.

## 4. Các bước tái hiện (Steps to Reproduce)

### Test case TC-B2 — Name rỗng:
1. Đăng nhập và lấy JWT token.
2. Gửi request `PUT /api/users/me` với header `Authorization: Bearer <token>` và body:
   ```json
   {
     "name": "",
     "phone": "0912345678"
   }
   ```
3. Quan sát response: `200 OK` — hồ sơ được cập nhật.

### Test case TC-B3 — Name chỉ có space:
1. Gửi request với `name: "   "`.
2. Quan sát response: `200 OK` — hồ sơ được cập nhật.

### Test case TC-B4 — Name null:
1. Gửi request với `name: null`.
2. Quan sát response: `200 OK` — hồ sơ được cập nhật.

### Test case TC-B5 / BV-N3 — Name > 255 ký tự:
1. Gửi request với `name: "A"*256`.
2. Quan sát response: `200 OK` — hồ sơ được cập nhật.

**Môi trường test:** Local, công cụ: Postman

## 5. Giả thuyết hành vi (Behavioral Hypothesis)

> Đây là suy luận **black-box động** (dynamic behavioral inference) dựa trên quan sát qua API, không phải đọc source code.

- **Giả thuyết:** Backend hoàn toàn không validate trường `name` ở tầng application. Có thể:
  - Backend nhận `name` và lưu trực tiếp vào CSDL mà không kiểm tra.
  - Không có required validation cho trường name.
  - Không có max length validation cho trường name.
- **Mức độ tin cậy:** `Cao` — cả 4 test case đều cho kết quả rõ ràng: backend không validate gì cả.
- **Test case bổ sung cần chạy để xác nhận:**
  - Kiểm tra CSDL xem name được lưu với giá trị gì (rỗng, null, 256 ký tự).
  - Kiểm tra GET /api/users/me sau khi update để xác nhận giá trị lưu.
