# [FR-04][Bug] Backend không validate `shipping_address` rỗng — chấp nhận địa chỉ rỗng và null

**Labels:** `bug`, `FR-04`, `black-box-testing`, `severity: medium`

---

## 1. Tóm tắt (Summary)

Endpoint `PUT /api/users/me` không validate trường `shipping_address`. Backend chấp nhận cả địa chỉ rỗng (`""`) và null mà vẫn trả về `200 OK` và cập nhật vào CSDL. Điều này có thể gây ra dữ liệu không nhất quán trong hệ thống.

---

## 2. Nguồn spec / kỳ vọng (Expected Behavior)

- **Tài liệu tham chiếu:** `contexts/README.md` — FR-04 §2, dòng 64
- **Trích nội dung spec:**
  > "Người dùng đã đăng nhập có thể cập nhật: **Địa chỉ giao hàng mặc định**."
- **Mức độ rõ ràng của spec:** `[Cần xác nhận]` — spec không nêu rõ shipping_address có bắt buộc không. Tuy nhiên, địa chỉ giao hàng mặc định nên có nội dung hợp lệ nếu được cập nhật.

## 4. Các bước tái hiện (Steps to Reproduce)

### Test case TC-D3 — Address rỗng:
1. Đăng nhập và lấy JWT token.
2. Gửi request `PUT /api/users/me` với body:
   ```json
   {
     "name": "Test User",
     "phone": "0912345678",
     "shipping_address": ""
   }
   ```
3. Quan sát response: `200 OK` — hồ sơ được cập nhật với shipping_address = "".
4. Gọi `GET /api/users/me` để xác nhận: shipping_address được lưu là "".

### Test case TC-D4 — Address null:
1. Gửi request với `shipping_address: null`.
2. Quan sát response: `200 OK` — hồ sơ được cập nhật.
3. Gọi `GET /api/users/me` để xác nhận: shipping_address được lưu là null.

**Môi trường test:** Local, công cụ: Postman

## 5. Giả thuyết hành vi (Behavioral Hypothesis)

> Đây là suy luận **black-box động** (dynamic behavioral inference) dựa trên quan sát qua API, không phải đọc source code.

- **Giả thuyết:** Backend không validate trường `shipping_address`. Backend nhận và lưu giá trị rỗng hoặc null trực tiếp vào CSDL.
- **Mức độ tin cậy:** `Cao` — quan sát rõ ràng: shipping_address được cập nhật với giá trị rỗng/null.
- **Test case bổ sung cần chạy để xác nhận:**
  - Kiểm tra CSDL xem shipping_address được lưu với giá trị gì.
  - Kiểm tra xem việc có shipping_address rỗng/null có ảnh hưởng đến chức năng đặt hàng không.
