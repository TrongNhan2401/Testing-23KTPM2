# [FR-16][Bug] Backend không validate `category_id` — chấp nhận category không tồn tại, null, và thiếu trường

**Labels:** `bug`, `FR-16`, `black-box-testing`, `severity: critical`

---

## 1. Tóm tắt (Summary)

Endpoint `POST /api/admin/import-products` không validate trường `category_id`. Backend chấp nhận tất cả các giá trị không hợp lệ (category_id không tồn tại, null, bằng 0, và hoàn toàn không gửi trường) và vẫn trả về `200 OK`, tạo sản phẩm thành công. Điều này vi phạm FR-15 và FR-16: "Danh mục: bắt buộc, phải chọn từ danh sách có sẵn."

---

## 4. Các bước tái hiện (Steps to Reproduce)

### Test case TC-D2 — Category không tồn tại:
1. Đăng nhập với tài khoản admin.
2. Gửi request `POST /api/admin/import-products`:
   ```json
   {
     "products": [
       {
         "name": "Sản phẩm Test",
         "price": 100000,
         "category_id": 9999
       }
     ]
   }
   ```
3. Quan sát response: `200 OK` — sản phẩm được thêm với category_id = 9999 (không tồn tại).

### Test case TC-D3 — Category null:
1. Gửi request với `category_id: null`.
2. Quan sát response: `200 OK` — sản phẩm được thêm.

### Test case TC-D4 — Thiếu category_id:
1. Gửi request không có trường `category_id`:
   ```json
   {
     "products": [
       {
         "name": "Sản phẩm Test",
         "price": 100000
       }
     ]
   }
   ```
2. Quan sát response: `200 OK` — sản phẩm được thêm.

### Test case TC-D5 — Category = 0:
1. Gửi request với `category_id: 0`.
2. Quan sát response: `200 OK` — sản phẩm được thêm.

**Môi trường test:** Local, công cụ: Postman

## 5. Giả thuyết hành vi (Behavioral Hypothesis)

> Đây là suy luận **black-box động** (dynamic behavioral inference) dựa trên quan sát qua API, không phải đọc source code.

- **Giả thuyết:** Backend không kiểm tra foreign key constraint cho `category_id`. Có thể:
  - Bảng `products` không có FK constraint tham chiếu đến bảng `categories`.
  - Backend không validate xem `category_id` có tồn tại trong bảng `categories` không.
  - Không có required validation cho trường category_id.
- **Mức độ tin cậy:** `Cao` — cả 4 test case đều cho kết quả rõ ràng: backend không validate gì cả.
- **Test case bổ sung cần chạy để xác nhận:**
  - Kiểm tra CSDL xem sản phẩm được lưu với category_id gì.
  - Kiểm tra xem sản phẩm có hiển thị đúng category trên UI không.
