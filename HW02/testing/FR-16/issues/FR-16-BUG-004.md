# [FR-16][Bug] Backend không validate `price` — chấp nhận price = 0, âm, null, và thiếu trường

**Labels:** `bug`, `FR-16`, `black-box-testing`, `severity: critical`

---

## 1. Tóm tắt (Summary)

Endpoint `POST /api/admin/import-products` không thực hiện bất kỳ validation nào đối với trường `price`. Backend chấp nhận tất cả các giá trị không hợp lệ (price = 0, số âm, null, và hoàn toàn không gửi trường) và vẫn trả về `200 OK`, tạo sản phẩm thành công. Điều này vi phạm trực tiếp FR-15 và FR-16: "Giá: bắt buộc, phải là số dương (> 0)."

## 4. Các bước tái hiện (Steps to Reproduce)

### Test case TC-C2 — Price = 0:
1. Đăng nhập với tài khoản admin.
2. Gửi request `POST /api/admin/import-products`:
   ```json
   {
     "products": [
       {
         "name": "Sản phẩm Test",
         "price": 0,
         "category_id": 1
       }
     ]
   }
   ```
3. Quan sát response: `200 OK` — sản phẩm được thêm với price = 0.

### Test case TC-C3 — Price âm:
1. Gửi request với `price: -100`.
2. Quan sát response: `200 OK` — sản phẩm được thêm với price = -100.

### Test case TC-C4 — Price null:
1. Gửi request với `price: null`.
2. Quan sát response: `200 OK` — sản phẩm được thêm.

### Test case TC-C5 — Thiếu price:
1. Gửi request không có trường `price`:
   ```json
   {
     "products": [
       {
         "name": "Sản phẩm Test",
         "category_id": 1
       }
     ]
   }
   ```
2. Quan sát response: `200 OK` — sản phẩm được thêm.

## 5. Giả thuyết hành vi (Behavioral Hypothesis)

> Đây là suy luận **black-box động** (dynamic behavioral inference) dựa trên quan sát qua API, không phải đọc source code.

- **Giả thuyết:** Backend hoàn toàn không validate trường `price` ở tầng application. Có thể:
  - Trường `price` trong bảng `products` được định nghĩa là kiểu số nhưng không có constraint CHECK > 0.
  - Backend không kiểm tra giá trị price trước khi insert.
  - Không có required validation cho trường price.
- **Mức độ tin cậy:** `Cao` — cả 4 test case đều cho kết quả rõ ràng: backend không validate gì cả.
- **Test case bổ sung cần chạy để xác nhận:**
  - Kiểm tra CSDL xem sản phẩm được lưu với giá trị price gì (0, null, -100).
  - Test với giá trị cực lớn (VD: 999999999999) — xem có overflow không.
